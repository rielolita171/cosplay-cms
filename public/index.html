How this install is protected

There is no login and no password. These are the only boundaries, so they are worth being able to see at a glance.

None of this hides your collection from whoever owns this machine — the database file is readable on disk. It stops other software, and it stops web pages. See ELECTRON.md for the details.

CORS allowed origins

The browser origins allowed to call this server from another hostname. A plain http:// origin is flagged, because traffic to it is unencrypted.

Origin restrictions are switched off. CMS_ALLOW_ANY_ORIGIN is set, so every browser origin is accepted and this list is not enforced. Unset it and restart the app to bring the allowlist back.

While it is on, any page you visit in any browser on this computer could read and change your collection.

Telegram notifications

This server checks your lenses once a day on its own — no external scheduler needed. If anything has entered the alert window below, you get one Telegram message naming it, and nothing is repeated until it enters a tighter window. You can try it right now with the buttons at the bottom.
